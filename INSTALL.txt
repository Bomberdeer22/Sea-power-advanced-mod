==============================================================================
INSTALLING SEA POWER ADVANCED
==============================================================================

A complete walkthrough from a stock Sea Power install. Allow 20 minutes the
first time; most of it is the one-time .NET SDK download in step 3.

You do this once. After that, updating the mod is step 3 again (-Install) and
a game restart.

------------------------------------------------------------------------------

BEFORE YOU START
----------------

  * Sea Power installed through Steam.
  * Windows. (Linux/Steam Proton works too  -  see Linux notes (#linux--steam-
    proton) at the end.)
  * No installer and no admin rights are needed. The .NET SDK the build uses
    is downloaded into this repo folder in step 3, not into Windows.

Two things get installed around the mod:

  BepInEx
      What it is: Unity's mod loader
      Why: Loads code mods at all.

  Anchor Chain
      What it is: Sea Power's mod loader, on top of BepInEx
      Why: Finds and loads DLL mods from StreamingAssets and the Workshop.

Both arrive together in step 1.

------------------------------------------------------------------------------

STEP 1  -  INSTALL THE ANCHOR CHAIN PRELOADER
---------------------------------------------

This is the only part with a manual file copy. It installs BepInEx and the
Anchor Chain preloader in one go.

  1. Open the Anchor Chain releases page: <https://github.com/SeaPower-
     Modders/AnchorChain/releases>
  2. Under the newest release, download ACPreloader.zip.
  3. Extract the zip into a folder in your Downloads.
  4. In that folder you will see winhttp.dll, doorstop_config.ini and a
     BepInEx folder. Select everything inside the folder (Ctrl+A), copy it
     (Ctrl+C).
  5. Open your game folder: in Steam, right-click Sea Power -> Manage ->
     Browse local files. It is usually C:\Program Files
     (x86)\Steam\steamapps\common\Sea Power.
  6. Paste (Ctrl+V). Say yes if Windows asks about merging folders.
  7. Check the game folder now contains winhttp.dll, doorstop_config.ini and
     BepInEx, next to Sea Power.exe. If yes, this step is done.
  8. Start Sea Power once and quit it. This lets BepInEx generate its folders
     and log file.

STEP 2  -  SUBSCRIBE TO ANCHOR CHAIN
------------------------------------

  1. Open the Workshop page:
     <https://steamcommunity.com/sharedfiles/filedetails/?id=3380210757>
  2. Click Subscribe. Steam downloads it.
  3. Start Sea Power, open the Mod Manager, and check that Anchor Chain is
     ticked.

If the Mod Manager shows "The Anchor Chain preloader is not running!", step 1
did not copy the files into the right folder  -  revisit it before going
further.

  Where it landed: Steam puts Workshop items in
  <steam>\steamapps\workshop\content\1286220\3380210757\. That is where this
  project looks for
  AnchorChain.dll when building.

------------------------------------------------------------------------------

STEP 3  -  BUILD THE MOD
------------------------

The mod is compiled against your game's own DLLs, so it always matches your
Sea Power version. There is no prebuilt download; the build takes about two
minutes and downloads a compiler the first time.

3a. Double-click build.cmd

That is the whole step. It:

  1. finds a .NET SDK  -  either one already installed, or it downloads a
     portable one into .dotnet\ (about 220 MB, once, no installer, no admin
     rights),
  2. finds your game folder and Anchor Chain by itself (Steam registry, then
     the usual library locations),
  3. compiles the mod against your Seapower-Scripts.dll,
  4. copies it into BepInEx\plugins\SeaPowerAdvanced\.

Expected output ends with:

    [3/4] Building the mod...
          build succeeded.
    [4/4] Packaging...
          package ready: ...\dist\SeaPowerAdvanced
    [install] Copying into the game...
           copied to C:\Program Files (x86)\Steam\steamapps\common\Sea Power\BepInEx\plugins\SeaPowerAdvanced

It pauses when it finishes, so the window stays open. Two files are written
next to it:

  build-log.txt
      What it is: Which steps ran, and the result of each. Survives the
        window closing.

  build-output.txt
      What it is: The compiler's full output. This is the file to send if
        the build fails.

build.cmd uses no PowerShell at all  -  it downloads with curl and unpacks
with tar, both of which are part of Windows 10 and 11. That matters on a
machine where PowerShell is restricted: the errors is not digitally signed, or
a PowerShell window that closes itself, cannot happen here.

To build without installing: build.cmd dist. To install without rebuilding,
just run it again.

If it could not find the game

It writes Directory.Build.local.props for you and prints the paths it needs.
Open that file in Notepad, set the two paths, save, and run build.cmd again:

    <SeaPowerDir>C:\Program Files (x86)\Steam\steamapps\common\Sea Power</SeaPowerDir>
    <AnchorChainDir>C:\Program Files (x86)\Steam\steamapps\workshop\content\1286220\3380210757</AnchorChainDir>

AnchorChainDir is the Workshop folder that contains AnchorChain.dll  -  its
number (3380210757) is the same on every PC.

The PowerShell route (optional)

If you prefer PowerShell and it works on your machine:

    .\tools\build-portable.ps1 -Install

It does the same job. If PowerShell is restricted on your PC, this is the
wrong route  -  use build.cmd, which never invokes it.

"is not digitally signed"  -  why it happens, and what to do

Windows marks files downloaded from the internet, and PowerShell's execution
policy then refuses to run .ps1 files that are not signed. It is not a problem
with the mod, and nothing about your PC needs changing.

The only reliable fix on a locked-down machine is to not use a PowerShell
script at all:

Use build.cmd. Batch files are not covered by the execution policy, so it
works even when MachinePolicy or UserPolicy is set to AllSigned by IT, where
-ExecutionPolicy Bypass is ignored and Unblock-File changes nothing.

------------------------------------------------------------------------------

STEP 4  -  START THE GAME
-------------------------

-Install puts the DLL in BepInEx\plugins\SeaPowerAdvanced\, so BepInEx loads
it directly. There is no mod-manager checkbox to tick on this route: the
plugin is present, so it runs.

If you previously installed it into StreamingAssets\SeaPowerAdvanced\, delete
that folder. A copy in both places is loaded twice; the installer prints a
warning when it sees one.

Why this route: a copy in StreamingAssets is only started if AnchorChain's own
loader recognises and triggers it, and on some installs that trigger never
happens  -  the game log shows the assembly being loaded but never says Loaded
plugin Sea Power Advanced. The BepInEx route has no such step.

STEP 5  -  CHECK IT LOADED
--------------------------

Two things to look at.

1. BepInEx's plugin list, near the top of BepInEx\LogOutput.log. It must say:

    [Info   :   BepInEx] Loading [Sea Power Advanced 0.6.0]

2. The mod's own log, BepInEx\plugins\SeaPowerAdvanced\seapoweradvanced.log.
This file only exists if the code actually ran, which makes "did it load?"
unambiguous:

    ================ Sea Power Advanced 0.6.0 ================
    Entry point:  BepInEx plugin
    Settings: enabled=True includeGuns=False allowEnemyUnits=False showWhenNoMounts=True
    Patched MapUnitViewModel.GetContextMenuItems.
    Patched ObjectBaseViewModel.GetContextMenuItems.
    Hatch menu installed.
    Ready. Right-click a ship > Orders > Weapon hatches.

If you see no patches installed instead, the box in the Mod Manager is not
ticked (or the game was not restarted). If you see nothing at all, Anchor
Chain is not loading the DLL  -  re-check step 1.

------------------------------------------------------------------------------

STEP 6  -  USE IT
-----------------

  1. Start a mission with a ship that has launchers  -  a Ticonderoga, Arleigh
     Burke, Spruance or Kirov is ideal.
  2. Right-click the ship -> Orders -> Weapon hatches.
  3. Pick a mount, then click a cell. It opens, the check mark appears, and
     the log records it:  [Info] Sea Power Advanced: Open Ticonderoga / Cell
     7: openHatches -> started [open=yes, hatches=1]

  4. Click the same cell again to close it. Open all hatches does the ship in
     one click.

Useful to know:

  * The menu lists cells, not individual lids. A cell with several hatch
    models opens them together  -  that is what the game's own openHatches()
    does.
  * The game still owns the hatches during a launch; if the ship fires, it may
    reopen or close what it needs and your last manual order can be
    overridden. The check marks always show the truth.
  * Log hatch report writes hatch-report.txt next to the DLL, in
    BepInEx\plugins\SeaPowerAdvanced\  -  that is the file to send if
    something does not move.

------------------------------------------------------------------------------

UPDATING OR REBUILDING
----------------------

    build.cmd

then fully restart the game. Close Sea Power before rebuilding, or the DLL is
locked.

UNINSTALLING
------------

  1. Delete BepInEx\plugins\SeaPowerAdvanced\.
  2. If an older release was installed into Sea
     Power_Data\StreamingAssets\SeaPowerAdvanced\, delete that folder too  -
     leaving it means the mod loads twice.
  3. Optional cleanup: delete .dotnet\, dist\ and
     BepInEx\config\io.github.bomberdeer22.seapoweradvanced.cfg.

To remove Anchor Chain itself, unsubscribe on Steam and delete winhttp.dll,
doorstop_config.ini and the BepInEx folder from the game directory.

------------------------------------------------------------------------------

IF SOMETHING GOES WRONG
-----------------------

Run diagnose.cmd (double-click it in the repo folder). It writes one file,
SeaPowerAdvanced-diagnose.txt, containing the game folder it found, which
files are present, the game's own LogOutput.log, the mod's log, and a check of
the analysis tools. Send that file  -  it answers almost every "it doesn't
work" question without anyone needing to copy console text.

It uses only cmd.exe: no PowerShell, no admin rights, nothing changed.

TROUBLESHOOTING
---------------

  dotnet : The term ... is not recognized
      Cause and fix: You ran build.ps1 directly without a .NET SDK. Use
        build.cmd instead  -  it fetches one.

  Sea Power not found. Set SeaPowerDir in Directory.Build.local.props
      Cause and fix: You skipped 3a, or the path has a typo. It must contain
        Sea Power_Data\Managed.

  AnchorChain.dll not found
      Cause and fix: Anchor Chain is not subscribed (step 2), or
        AnchorChainDir points at the wrong folder.

  error CS0117: ... does not contain a definition
      Cause and fix: The game's API moved in an update. Send me the full
        error  -  it names the member exactly.

  .ps1 cannot be loaded ... is not digitally signed
      Cause and fix: Execution policy. Use build.cmd  -  it runs no
        PowerShell at all. See why (#is-not-digitally-signed--why-it-happens-
        and-what-to-do).

  The build window opens and closes instantly
      Cause and fix: Fixed: build.cmd now pauses. If it still happens, open
        build-log.txt  -  it records every step, and build-output.txt has the
        compiler's own errors.

  PowerShell itself crashes or closes when building
      Cause and fix: That is why build.cmd exists. It uses curl and tar
        (both built into Windows) instead of any script host.

  Build succeeds, but no Weapon hatches in game
      Cause and fix: Read
        BepInEx\plugins\SeaPowerAdvanced\seapoweradvanced.log. No file = the
        plugin never ran (check that step 5 shows Loading [Sea Power Advanced
        ...]). File present = the code ran, so send it.

  The Anchor Chain preloader is not running!
      Cause and fix: Step 1: winhttp.dll + doorstop_config.ini + BepInEx
        must be in the game folder.

  Menu entry appears but the submenu is empty
      Cause and fix: That mount has no hatch animation of its own. Run Log
        hatch report and send it.

  Click does nothing, log says cell has no open animation
      Cause and fix: Real result: that cell cannot be opened in this game
        build. Note the ship class.

  Hatch opens then shuts again immediately
      Cause and fix: The game's launch/reload cycle took it back. Note what
        the ship was doing and send the log.

Linux / Steam Proton

Build anywhere (the same ./tools/build-portable.sh --install works, with
SEAPOWER_DIR set), or build on another machine and copy dist/SeaPowerAdvanced/
across. Then copy that folder into .../steamapps/common/Sea
Power/BepInEx/plugins/.

For BepInEx under Proton you may also need the standard winhttp override:

    protontricks 1286220 --force winecfg   # Libraries -> add "winhttp" as native,builtin

------------------------------------------------------------------------------

WHAT WAS INSTALLED, AT A GLANCE
-------------------------------

    Sea Power\                                  <- game folder
    |-- winhttp.dll                             <- step 1 (BepInEx/Anchor Chain preloader)
    |-- doorstop_config.ini                     <- step 1
    +-- BepInEx\
        |-- LogOutput.log                       <- where to look when something is wrong
        |-- config\io.github.bomberdeer22.seapoweradvanced.cfg   <- settings
        +-- plugins\
            +-- SeaPowerAdvanced\               <- step 3 (the mod)
                |-- SeaPowerAdvanced.dll        <- loaded by BepInEx at startup
                |-- _info.ini                   <- name and description
                +-- seapoweradvanced.log        <- the mod's own log
